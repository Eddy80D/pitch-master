01

四形态 · 状态语义

与评委三态同款 3D 化风格 · 情绪全靠姿势与特效

就位等待IDLE

STATE-00

加载页 / 评委入场中。端坐，无特效，全场灯光聚焦舞台。

答辩打字ANSWERING

STATE-01

选手答题中。头顶浮现语音气泡（打字指示点），替他说出回答。

欢呼CHEER · ≥3 灯

STATE-02

三灯及以上！双臂举拳，头顶闪电特效，烟花 + 彩带两侧齐放，会场沸腾。

失落SAD · <3 灯

STATE-03

不足三灯。垂头、手臂垂落、冷汗滑落，整个场地暗下来，只剩一束追光。

02

状态流 · 交互映射

给架构的状态机对接表
进入会场→就位等待（IDLE）：无特效，等待评委入席
开始答辩→答辩打字（ANSWERING）：语音气泡 + 打字指示点，气泡内容 = LLM 生成的选手回答
亮灯 ≥ 3→欢呼（CHEER）：举拳 + 头顶闪电 + 烟花 + 彩带（暖色粒子系统）
亮灯 < 3→失落（SAD）：垂头 + 冷汗 + 全场背景调暗（亮度 → 25%） + 单束追光保留
💡 设计要点：选手无五官——情绪全部由「姿势 + 特效 + 场地灯光」表达。这样任何团队成员都能在他身上代入自己，也让「灯光裁决」成为唯一的表情。三态色语义与评委卡一致：欢呼=暖色、失落=冷色压暗。
